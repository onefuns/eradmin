# 에그라우터 통합 관리자 공식 HTML 프리뷰

기존 `inforouter.co.kr` 관리자의 메뉴·검색·목록·입력 흐름을 기준으로 재구성한 정적 프리뷰다.

- 조직: 대리점 → 판매점 → 영업점
- 제외: 사용하지 않는 `충전 주문 요청(old)`, 별도 `개통 요청` 메뉴·화면
- 유지: 재고, 신규 주문, 충전 주문 요청, 판매 관리, 판매 현황, 충전내역·예약, 정산, 코드, 계정, 로그
- 추가: 판매점의 영업점 관리·영업점 공급가
- 추가: 판매점·영업점별 TON·USDT TRC20·상담형 수동 결제 설정과 결제 요청 관리
- 결제설정: 네이버페이·카카오페이·무통장입금·TON·USDT TRC20 5종, 암호화폐 지갑주소와 Telegram 상담결제 흐름
- 쇼핑몰 콘텐츠: 공지사항, FAQ, 이용약관·개인정보처리방침 버전 관리
- 대리점: 판매조직 결제 연동의 정상·오류·중지 상태만 확인

모든 데이터와 저장 버튼은 목업이며 운영 시스템에 연결되지 않는다.

대응 개발명세는 `../project-spec/ADMIN_SPEC.md`, 통합 버전과 변경이력은 `../project-spec/VERSION.md`, `../project-spec/CHANGELOG.md`를 따른다.
