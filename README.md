# 통합 관리자 HTML 프리뷰

기존 관리자 업무 흐름과 선택형 Telegram Mini App 쇼핑몰을 하나의 운영 구조로 보여주는 정적 HTML 프리뷰입니다.

## 실행

- `index.html`을 브라우저에서 직접 열거나 정적 서버로 실행합니다.
- 별도 설치와 빌드가 필요하지 않습니다.

## 확인할 수 있는 내용

- 대리점 / 판매점 / 영업점 역할 전환
- 기존 관리자 메뉴 순서와 검색·목록·상태 중심 UI를 확장한 역할별 화면
- 신규 장비·패키지·단독 USIM/eSIM 구매를 처리하는 `신규 주문 요청` 목록
- 기존 회선의 USIM/eSIM 기간 연장을 처리하는 `충전 주문 요청` 목록
- 기존 `판매 관리`, `판매 현황`, `충전내역 및 예약현황` 화면과 상세 폼
- 결제완료 → 재고예약 → 발주승인 → 개통·충전·배송 → 정산 흐름
- 대리점 전용 장비·USIM/eSIM·요금제·패키지 상품 등록 폼
- 장비 + USIM/eSIM + CTN + 요금제를 미리 세팅한 판매 준비 재고 세트
- 결제완료 예약과 발주완료 시 판매조직·고객 확정 매칭
- 판매점 직접판매와 영업점 2단계 발주 승인
- 판매점·영업점별 고객 판매가, 이미지, 상품명, 상세설명, 노출 상태 관리
- 대리점→판매점 공급가와 판매점→영업점 공급가를 고객 판매가와 분리
- A006 Model·A009 요금제 코드에서 연결 상품과 대리점 공급가 조회·수정
- 판매점이 소속 영업점별 장비·요금제·패키지 공급가를 설정하는 가격표
- 판매점별 미정산 주문 조회와 주문 건 체크 선택 방식의 부분정산
- 쇼핑몰 사용 여부, Bot 연결 상태, 브랜딩 관리
- 상품 패키지, 개통·충전·배송, 고객, 코드관리, 감사로그 목업 데이터
- 대리점은 판매점만, 판매점은 영업점을 관리하는 역할별 조직 화면
- 신규주문, 충전주문, 판매 상세, 충전 이력, 코드, 조직, 공급가의 등록·수정 폼
- 사용하지 않는 `개통 요청`과 `충전 주문 요청(old)` 메뉴 제외

모든 데이터와 버튼 동작은 프리뷰용입니다. 실제 관리자 시스템이나 운영 데이터와 연결되지 않습니다.
